# AI Agent 课程与教程集

概述 GitHub 上最热门的 AI Agent 相关课程和教程资源。

## 综合课程（英文）

### 1. NirDiamant/GenAI_Agents ⭐21.7k
[GenAI_Agents](/docs/genai_agents) — 50+ 教程覆盖 GenAI Agent 全技术栈。从对话机器人到高级 Agent 模式，含 RAG、工具调用、多 Agent 协作、记忆系统。
- 作者同系列：[agents-towards-production](/docs/agents-towards-production)

### 2. NirDiamant/agents-towards-production ⭐19.0k
[agents-towards-production](/docs/agents-towards-production) — 端到端生产级 GenAI Agent 教程。代码优先，覆盖原型→测试→部署→监控全链路。

### 3. ed-donner/agents ⭐4.9k
[agents-course](/docs/agents-course) — "Complete Agentic AI Engineering Course"。6 周课程，从 OpenAI API 到多 Agent 系统，Udemy 同款。
- 关联：[agent-course-notebooks](/docs/agent-course-notebooks)

### 4. microsoft/GenAI_Agents (NirDiamant 维护)
同上 #1，社区维护版本。

## 中文课程

### 5. adongwanai/AgentGuide ⭐4.5k
[AgentGuide](/docs/agentguide) — AI Agent 开发指南。LangGraph 实战 + 高级 RAG + 大模型面试。中文社区最系统的 Agent 教程之一。

### 6. didilili/ai-agents-from-zero ⭐671
[ai-agents-from-zero](/docs/ai-agents-from-zero) — 2026 最系统的 AI Agent 速成指南。完整学习路径 + 实战项目 + 面试题库，对标大模型应用开发工程师岗位。
- 覆盖：LangChain / LangGraph / MCP / RAG / 多 Agent

### 7. Annyfee/agent-craft ⭐301
[agent-craft](/docs/agent-craft) — AI Agent 教学仓库。系统化 LangChain、RAG、LangGraph、MCP 全栈实战代码，万字博客详解。
