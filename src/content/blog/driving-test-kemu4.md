# 科目四（安全文明驾驶常识考试）

## 概述

科目四是科目三路考之后的安全文明驾驶常识考试，俗称"科目四"。官方说法中没有"科目四"这一名称，而是归在科目三的"安全文明驾驶常识考试"部分。2026 年继续沿用最新交规题库。

**考试形式：** 电脑答题，50 道题，每题 2 分，90 分合格。
**题型分布：**
- 判断题 22 题
- 单选题 23 题
- 多选题 5 题（每题 2 分，多选/少选/错选均不得分）

---

## 核心考点（按章节）

### 一、安全行车常识
1. **安全带**：所有驾乘人员都必须系好安全带（包括后排）
2. **安全头枕**：头枕中心与头平齐，保护颈椎
3. **灯光使用**：
   - 有路灯/照明良好 → 近光灯
   - 无路灯/照明不良 → 远光灯
   - 会车 150 米外 → 近光灯
   - 超车 → 左转向灯（提前开启）
   - 雨雾天 → 雾灯 + 近光灯 + 示廓灯
4. **后视镜**：调整到能看到车身和后方 1/4 视野
5. **车速控制**：
   - 无中心线城市道路 30km/h，公路 40km/h
   - 有中心线城市道路 50km/h，公路 70km/h
6. **跟车距离**：车速超过 100km/h → 100 米以上；低于 100km/h → 50 米以上

### 二、文明驾驶常识
1. **让行原则**：
   - 转弯让直行
   - 右转让左转
   - 支路让干路
   - 未让行先行道路的车辆让行
   - 下坡让上坡（下坡车让上坡车先行）
2. **超车规则**：
   - 左侧超车
   - 禁止右侧超车
   - 前车左转/掉头/超车时不得超车
   - 路口/人行横道/弯道/窄桥/隧道禁止超车
3. **会车**：有障碍一方让无障碍一方
4. **鸣喇叭**：禁止在禁鸣区域、夜间（特殊路段）、医院/学校附近鸣喇叭
5. **停车**：
   - 禁止在路口、人行横道、公交站 30 米内停车
   - 禁止在弯道、陡坡、隧道 50 米内停车

### 三、天气与复杂路况驾驶
1. **雨天**：
   - 减速慢行
   - 开启近光灯/示廓灯
   - 避免紧急制动
   - 路面附着系数降低 → 制动距离延长
2. **雾天**：
   - 开启雾灯 + 近光灯 + 示廓灯 + 危险报警闪光灯
   - 禁止使用远光灯（反射更看不清）
   - 限速：能见度＜50m → 20km/h
3. **雪天**：
   - 开启近光灯 + 示廓灯
   - 与前车保持更长距离
   - 沿前车车辙行驶
4. **夜间**：
   - 夜间会车 150 米外改用近光灯
   - 夜间通过路口/人行横道 → 交替使用远近光灯
   - 夜间超车 → 交替使用远近光灯提示前车
5. **山区道路**：
   - 上坡：保持足够动力，提前换低挡
   - 下坡：充分利用发动机制动，避免长时间踩刹车
   - 弯道：减速鸣号靠右行

### 四、高速公路驾驶
1. **进入高速**：加速车道提速至 60km/h 以上
2. **车速限制**：60~120km/h
   - 最低限速：60km/h（左车道通常 100~120km/h）
3. **行车间距**：100km/h 以上 → 100 米以上；低于 100km/h → 50 米以上
4. **驶离高速**：提前变道至右车道，减速驶出
5. **机动车在高速公路上发生故障**：
   - 开启危险报警闪光灯
   - 移至应急车道（或路肩）
   - 150 米外放置警示牌（夜间适当延长）
   - 人员撤离到护栏外

### 五、紧急情况避险
1. **制动失灵**：
   - 抢挂低挡（逐级降挡）
   - 利用驻车制动减速
   - 借助避险车道或障碍物减速
2. **转向失灵**：立即减速，松开加速踏板
3. **轮胎爆裂**：
   - **前轮爆胎**（更危险）→ 握紧方向，松油门，轻踩制动
   - **后轮爆胎** → 握紧方向，松油门，反复轻踩制动
4. **侧滑**：方向盘向侧滑方向轻打（不要反打）
5. **落水**：尽快弃车逃生（水压平衡后开车门/破窗）
6. **碰撞**：
   - 侧面碰撞 → 身体向另一侧倾斜
   - 正面碰撞 → 两腿向前蹬，身体后倾
7. **火灾**：关闭发动机 → 使用灭火器（站在上风处）
8. **化学品泄漏**：逆风逃离，不可站在下风处

### 六、交通事故急救
1. **急救原则**：先救命后治伤
2. **伤员搬运**：怀疑脊柱骨折 → 禁止随意搬动（可能导致截瘫）
3. **止血**：
   - 加压包扎止血（最常用）
   - 止血带止血（标注时间，每隔 1 小时放松 5 分钟）
   - 压迫止血（动脉出血 → 压迫近心端）
4. **烧伤**：用冷水冲洗降温
5. **中毒**：立即转移到空气新鲜处
6. **心肺复苏**：胸外按压与人工呼吸比例 30:2（按压深度 5~6cm，频率 100~120 次/分）

### 七、常见违法行为和处罚
1. **酒驾**：酒驾 20~80mg/100ml → 暂扣驾照 6 个月 + 罚款 1000~2000；醉驾 ≥80mg/100ml → 吊销驾照 + 刑事责任（5 年内不得重考）
2. **超速**：超速 50% 以上 → 吊销驾照
3. **肇事逃逸**：终身禁驾（构成犯罪的）
4. **驾驶证有效期**：6 年 → 10 年 → 长期
5. **计分**：满分 12 分。累计记分 12 分 → 参加学习+考试

## 答题技巧

### 判断题
- **看到"只要"、"只需"、"只有"等绝对词** → 一般为错误
- **看到"不准"、"不得"、"严禁"、"禁止"** → 一般为正确
- 安全带、安全气囊 → 考安全（正确方向）
- 紧急制动/急转向 → 通常是错误操作（正确做法是逐级减速）

### 多选题
- 关键词记忆：仔细观察、提前减速、谨慎驾驶
- 太多选项全选一般是正确答案（4 个选项全选的情况很常见）
- 少选或错选 0 分，不确定宁可全选

### 速度类
- **口诀：** 无中心线城 3 公 4，有中心线城 5 公 7
  - 无中心线：城市 30，公路 40
  - 有中心线：城市 50，公路 70

### 高速公路能见度
- **口诀：** 261 / 145 / 520
  - 能见度＜200m → 车速≤60km/h，车距≥100m
  - 能见度＜100m → 车速≤40km/h，车距≥50m
  - 能见度＜50m → 车速≤20km/h，尽快驶离

### 让行规则
- **转弯让直行，右转让左转**
- **有障碍让无障碍**
- **下坡让上坡**
- **路口让行**：不进入路口等待，即便是绿灯

## 易错 / 高频真题精选

### 判断题

**1. 车辆下坡行驶，要适当控制车速，充分利用发动机进行制动。**
> ✅ **正确** — 下坡长时间踩刹车会导致刹车热衰减，应利用发动机制动配合

**2. 伤员骨折处出血时，先固定好肢体再进行止血和包扎。**
> ❌ **错误** — 先止血再固定，否则失血过多

**3. 在高速公路上遇到紧急情况时，可以急转方向避让。**
> ❌ **错误** — 高速急转会导致侧翻，应握稳方向减速

**4. 驾驶机动车驶离高速公路时，可以不必提前开启转向灯。**
> ❌ **错误** — 驶离高速公路必须提前开启右转向灯

**5. 在冰雪路面上行车，应降低车速，增大安全距离。**
> ✅ **正确**

### 单选题

**6. 驾驶机动车在高速公路行驶，遇到能见度小于100米时，车速不得超过多少？**
A. 60km/h
B. 40km/h ✅
C. 20km/h
D. 80km/h

> **解析：** 能见度＜100m → 车速≤40km/h，车距≥50m（口诀 **145**）

**7. 机动车在高速公路上发生故障，警告标志应设置在故障车来车方向多少米以外？**
A. 50米
B. 100米
C. 150米 ✅
D. 200米

**8. 行车中遇到前方道路拥堵时，应该怎么做？**
A. 鸣喇叭催促
B. 从右侧绕行
C. 依次排队等候 ✅
D. 占用对面车道

**9. 在普通道路上，机动车最高行驶速度不得超过多少？**
A. 30km/h
B. 40km/h
C. 50km/h
D. 取决于是否有中心线 ✅

> **解析：** 无中心线城30公40，有中心线城50公70

**10. 驾驶人在下列哪种情况下不能驾驶机动车？**
A. 喝过咖啡后
B. 服用感冒药后
C. 饮过酒后 ✅
D. 刚睡醒后

### 多选题

**11. 驾驶机动车在山区道路上坡路段行驶，正确的做法是？**
A. 提前换入低挡 ✅
B. 提前换入高挡
C. 保持足够动力 ✅
D. 下坡时利用发动机制动 ✅

> **答案：** ACD。上坡用低挡增加扭矩，保持动力；下坡利用发动机制动

**12. 驾驶机动车在雨天行驶，应该注意哪些事项？**
A. 减速慢行 ✅
B. 开启近光灯 ✅
C. 加大跟车距离 ✅
D. 紧急制动

> **答案：** ABC。避免紧急制动，雨天制动距离延长

**13. 发生交通事故后，防止二次事故的有效措施是什么？**
A. 疏散人员 ✅
B. 开启危险报警闪光灯 ✅
C. 设置警告标志 ✅
D. 原地等待救援

> **答案：** ABC。不能原地等待，人员应撤离到安全区域

**14. 驾驶机动车通过漫水路或漫水桥时，应该怎么做？**
A. 停车察明水情 ✅
B. 确认安全后低速通过 ✅
C. 快速通过
D. 关闭发动机

> **答案：** AB。漫水路段必须确认水深，低速通过，避免排气进水

**15. 以下哪些行为是交通法规明确禁止的？**
A. 驾驶时拨打接听手持电话 ✅
B. 驾驶时观看视频 ✅
C. 驾驶时使用蓝牙耳机通话
D. 驾驶时抽烟 ✅

> **答案：** ABD。蓝牙耳机通话虽不违法，但多选题中「最正确」的选法：法规明确禁止的有手持电话、视频、抽烟影响安全驾驶

### 交警手势速查

```
停止信号    → 左臂向上直伸，掌心向前
直行信号    → 双臂平伸，右臂向左摆动
左转弯信号  → 右臂向前平伸，左臂向右摆动
右转弯信号  → 左臂向前平伸，右臂向左摆动
变道信号    → 右臂向前平伸，向左摆动
减速慢行信号 → 右臂向右前方平伸，上下摆动
靠边停车信号 → 左臂向上直伸，右臂向左摆动
```
