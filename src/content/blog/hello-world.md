## 为什么开这个站？

之前一直在折腾各种 Agent 框架和工具，笔记散落在本地 Markdown 文件和 Obsidian 里。
时间长了发现一个问题：**记过的笔记自己找不到了**。

这个站就是用来解决这个问题的：

1. **博客** — 记录技术折腾过程和思考
2. **文档** — 沉淀可复用的知识和技术方案

## 打算写什么？

- AI Agent 的实践心得（Hermes / CoPaw 相关）
- 工具链的折腾记录
- 双城生活的零碎思考
- 偶尔的读书笔记

## 技术选型

这个站用的是 **Astro**，静态生成，性能好，Markdown 原生支持，写内容非常方便。

```shell
npm create astro@latest
```

就这样，开张。
