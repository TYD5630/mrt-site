用过 AI Agent 的人都有一个共同的困惑：**它老是记不住。**

其实不是记不住，是记忆系统的打开方式没对。这里分享一下我在 CoPaw/Hermes 里摸索出来的经验。

## AGENTS.md 的工作机制

Agent 的「长期记忆」依赖几个文件：

- `MEMORY.md` — 精心整理的精简记忆
- `PROFILE.md` — 用户画像，记录偏好和习惯
- `memory/YYYY-MM-DD.md` — 每日原始日志

关键原则是：**写下来，别靠脑子记。**

## 什么该记，什么不该记？

| 该记 | 不该记 |
|------|--------|
| 用户偏好和习惯 | 敏感信息（密码、密钥） |
| 重大决策和结论 | 无关的闲聊 |
| 技术配置和路径 | 临时状态的缓存 |
| 项目上下文 | 你在哪读到这些的 |

## 技能进化的理念

Hermes 框架里有一个很酷的设计叫 **技能进化**（Skill Evolution）：

> 复杂任务完成后，自动评估是否固化为一个可复用的技能。

这意味着 Agent 会随着使用越来越聪明 — 如果你总在做同一类事，它会学会把它变成 SOP。

## 小结

记忆系统的本质不是「存储」，而是 **检索**。写得好不好，决定了以后能不能找回来。
