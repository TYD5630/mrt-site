# Microsoft PowerToys

微软官方 Windows 系统增强工具集。单文件启动，开源免费。
⭐ 132.8k · microsoft/PowerToys

---

## 概述

PowerToys 是 Windows 高级用户的瑞士军刀。包含一系列系统增强工具，
无需安装第三方软件就能实现窗口管理、批量重命名、颜色拾取、截图OCR等常用功能。

## 核心工具

| 工具 | 功能 |
|:-----|:------|
| FancyZones | 自定义窗口布局管理器（分屏增强） |
| PowerToys Run | 快速启动器（Alt+Space，类似 Spotlight） |
| File Explorer Add-ons | 文件预览增强（SVG/MD/PDF 缩略图） |
| Image Resizer | 批量图片缩放 |
| Keyboard Manager | 键盘键位重映射 |
| PowerRename | 批量文件重命名（支持正则） |
| Peek | 文件快速预览（Ctrl+Space） |
| Text Extractor | 屏幕取词 OCR（截图识别文字） |
| Color Picker | 屏幕取色（Win+Shift+C） |
| Mouse utilities | 鼠标高亮/定位/跨界 |

## Windows 桌面绝配

PowerToys + [desktop-control](/docs/desktop-control) 中的批处理/pywebview 方案互补：
- PowerToys 做系统增强（窗口管理、快速启动）
- pywebview/pywinauto 做自动化（浮窗、控件操作）
