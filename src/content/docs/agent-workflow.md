## 任务处理流程

收到用户请求后，Agent 自动走以下处理链：

```
收到请求
  │
  ├─① 任务分级
  │   ├─ 简单 → 直接做
  │   ├─ 中等 → 先列计划再动手
  │   └─ 复杂 → 调研→方案→执行
  │
  ├─② 识别 20% 关键产出
  │
  ├─③ 技能匹配 → 加载 SKILL.md → 执行
  │
  ├─④ 执行 + 验证
  │
  └─⑤ 省 token 检查
```

## 技能调用链

```
收到任务
  ├─① 关键词匹配 INDEX.md + 技能名
  ├─② 类别匹配（文档/浏览器/邮件/定时）
  ├─③ 工具兜底（无匹配时）
  └─④ 复杂任务后评估是否创建新技能
```

## 任务分级

| 类型 | 行为 | 示例 |
|:----:|------|------|
| **简单** | 直接执行，不展开 | 问时间、读文件 |
| **中等** | 列计划再动手 | 多步骤操作 |
| **复杂** | 调研→方案→执行 | 跨系统改动 |

## 效率原则

1. **T 型回应** — 简单任务快答，复杂任务才展开
2. **YAGNI** — 不做没被要求的事
3. **工具优先** — 有工具调工具，没有才自己写
4. **写下来 > 脑子记** — GTD 核心理念
