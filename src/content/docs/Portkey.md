# Portkey

AI Gateway —— 统一 API 接入 200+ 模型，内置路由、护栏、Prompt 管理、可观测性。

## 功能
- 多 Provider 统一 API（OpenAI / Anthropic / Google / 自托管）
- 模型路由（自动 Fallback、A/B 测试）
- 成本追踪和用量分析
- Guardrails（安全护栏）
- Prompt 版本管理
