# agents-course

Ed Donner 的 "Complete Agentic AI Engineering Course"（4874★）。6 周课程，代码和部署实战。

## 课程结构（6 周）
1. OpenAI API 基础：Chat Completions、Token、JSON mode
2. Function Calling & Tool Use 深度实践
3. 多 Agent 系统设计：CrewAI、LangGraph
4. 记忆系统：短期记忆、长期记忆、RAG
5. 生产级部署：FastAPI、Docker、监控
6. 最终项目：端到端多 Agent 应用

## 亮点
- 完整 6 周 syllabus，每一步有代码
- 覆盖：OpenAI + LangChain + LangGraph + CrewAI
- 从 API 基础到多 Agent 系统到生产部署
- Udemy 付费课程的开源配套仓库
