# Tabby

自托管 AI 编程助手。类似 GitHub Copilot 但完全本地运行，
代码模型私有部署，数据不出服务器。
⭐ 33.5k · TabbyML/tabby

---

## 概述

Tabby 是目前最热门的自托管 AI 编程助手。核心优势是**隐私**和**离线可用**。
支持多种开源代码模型（StarCoder2、CodeLlama、DeepSeek Coder 等），
通过 IDE 插件（VS Code、JetBrains）提供代码补全和对话。

## 核心能力

| 能力 | 说明 |
|:-----|:------|
| 代码补全 | 行内/多行实时补全 |
| 对话 | 代码解释、重构、调试 |
| 私有化 | 本地运行，代码不出网 |
| 模型 | 支持多种开源代码模型 |
| IDE | VS Code / JetBrains / 终端 |
| 硬件事 | 推荐有 GPU（无 GPU 也可用 CPU） |

## 与 Copilot 对比

| 维度 | Tabby | GitHub Copilot |
|:-----|:-------|:---------------|
| 数据隐私 | ✅ 完全本地 | ❌ 代码发送到 GitHub |
| 价格 | 免费 | $10-19/月 |
| 离线 | ✅ 支持 | ❌ 需要联网 |
| 配置 | 需要自托管 | 开箱即用 |
| 模型质量 | 开源模型（接近但弱于 GPT-4） | 专有模型 |
