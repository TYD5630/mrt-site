# bytebot

自托管 AI 桌面 Agent。能理解自然语言指令并操作电脑完成任务，
全程本地运行，数据和指令不出设备。
⭐ 11k · bytebot-ai/bytebot

---

## 概述

bytebot 是自托管的"AI 操盘手"。你说"帮我整理下载文件夹"，它就能
打开文件管理器、创建目录、移动文件。完全本地运行。

## 核心能力

| 能力 | 说明 |
|:-----|:------|
| 自然语言指令 | 用自然语言描述任务 |
| 桌面操作 | 控制鼠标键盘操作任意应用 |
| 文件系统 | 读写文件、组织目录 |
| 浏览器 | 打开网页、提取信息 |
| 自托管 | 数据不出设备 |

## 适用场景

- 本地文件整理、批量重命名
- 表单填写、数据录入自动化
- 软件安装与配置
- 日常重复操作的 AI 替代
