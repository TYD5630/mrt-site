## Beginners Guide（新手指南）

> <https://fmhy.net/beginners-guide>

### Adblocking
- **浏览器端**：推荐 **uBlock Origin** + Redirect Skipper
- **移动端**：**AdGuard Premium** / **Rethink DNS**（Android），Safari+AdGuard / Brave（iOS）
- YouTube/Reddit 去广告：**Morphe**（模块化去广告/增强工具）
- ⚠️ 不要同时装多个广告拦截器（uBO + AdGuard 同时开会导致冲突）

### Antivirus
- 上传文件到 **VirusTotal** 扫描
- 普通用户 **Windows Defender + 定期 Malwarebytes 扫描** 足够
- 用靠谱网站比装一堆杀毒软件重要

### Browsers
- **桌面**：Firefox（推荐）/ Brave（Chromium 系）/ 隐私浏览器
- **Android**：Brave / Cromite / Firefox
- **iOS**：Safari+AdGuard / Brave

### Base64 解码
- FMHY 很多链接是 Base64 编码，用 Base64 Decoder 或 FMHY Auto Decode 油猴脚本

### Movies / Shows / Anime / Music / Gaming / Reading
- 每个分类都给了推荐的流媒体、下载、PT、发现/追踪服务

### Privacy
- 邮件：Proton，搜索：SearXNG
- 常查 HaveIBeenPwned
- 不要用真实邮箱/密码注册不信任的网站
- 不要上传私密文件到文件托管/AI 云

### Windows Guide
- ISO：Massgrave 的 Genuine Installation Media
- 激活：**Microsoft Activation Scripts（MAS）**
- 软件下载：Virgil Software Search / CracksURL / LRepacks

### Torrenting
- 大多数国家需要 VPN，**必须绑定到 BT 客户端**（断开 VPN 时自动停流量）
- 也可用 Remote Torrenting 服务免 VPN
- **端口转发（Port Forwarding）** 推荐开启，提升连接性

### Android / iOS 侧载
- **Android**：Mobilism（修改版）/ APKMirror（原始版）/ Droid-ify（FOSS）/ Obtainium
- **iOS**：TrollStore / SideStore / Sideloadly / Impactor
